### 摩尔投票(例子：力扣169题)
```
给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

 

示例 1：

输入：nums = [3,2,3]
输出：3
示例 2：

输入：nums = [2,2,1,1,1,2,2]
输出：2

```
##### 思路解释:
● 我们尝试“抵消”不同的元素
● 当 count = 0 时，换一个候选人
● 如果当前元素是候选人，count++，否则 count--
● 最终剩下的一定是多数元素（因为它“抵消”掉所有非多数）

``` python
def majorityElement(nums):
    count = 0
    candidate = None

    for num in nums:
        if count == 0:
            candidate = num
        count += 1 if num == candidate else -1

    return candidate
```
示例分析：
输入：[2,2,1,1,1,2,2]
##### 执行过程：
| 当前数 (`num`) | 当前候选人 (`candidate`) | 当前计数 (`count`) |
| ----------- | ------------------- | -------------- |
| 2           | 2                   | 1              |
| 2           | 2                   | 2              |
| 1           | 2                   | 1              |
| 1           | 2                   | 0              |
| 1           | 1                   | 1              |
| 2           | 1                   | 0              |
| 2           | 2                   | 1              |

    结果：2
